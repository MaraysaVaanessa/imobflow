# ImobFlow

Sistema de gestão inteligente para imóveis — centraliza a administração de imóveis, proprietários, inquilinos, contratos, financeiro, manutenções, agenda e relatórios.

## Tecnologias

- Frontend: React + TypeScript
- Backend: Node.js + TypeScript
- Banco de dados: PostgreSQL
- ORM: Prisma
- Estilização: Tailwind CSS

## Status do projeto

Em desenvolvimento — fase de planejamento e configuração inicial.
